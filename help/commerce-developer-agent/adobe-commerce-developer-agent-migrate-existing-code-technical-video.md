# Adobe Commerce Developer Agent migriert vorhandenen Code

Nicht jedes Projekt beginnt mit einer leeren Konfiguration. In diesem Beispiel wird eine bestehende Erweiterung zu App Builder migriert, wobei von der PaaS-Plattform auf Adobe Commerce as a Cloud Service umgestellt wird. Dabei wird das Migrationsbewertungs-Tool verwendet, um den Entwickleragenten zu befüllen.

## Für wen ist dieses Video bestimmt?

* Commerce-Entwickler
* Lösungsarchitekten
* Backend-Techniker

## Videoinhalt

* Überprüfen einer bestehenden Commerce-Instanz mit dem Migrationsbewertungs-Tool - Komplexitätsbewertungen, Auswirkungen pro Modul, Risikosignale und eine Empfehlung zum Neuaufbau, Umgestalten, Ersetzen oder Entfernen
* Überprüfung der Bewertung eines Moduls mit hoher Auswirkung, einschließlich seiner Erweiterungspunkte, Dateien und einer Zusammenfassung des Zwecks, die in einfacher Sprache verfasst ist und sofort angezeigt wird
* Senden der Bewertung direkt an den Entwickleragenten ohne manuelles Kopieren
* Um den ersten Durchgang auf bestimmte Funktionen zu konzentrieren, beantworten Sie die Fragen des Agenten zum Umfang
* Erstellen eines Blueprints aus synchronen Webhooks, die die riskanteste alte Logik ersetzen, mit einem Architekturdiagramm
* Erstellen der Implementierung mit einer passenden Testdatei, die zusammen mit jedem Handler geschrieben wird
