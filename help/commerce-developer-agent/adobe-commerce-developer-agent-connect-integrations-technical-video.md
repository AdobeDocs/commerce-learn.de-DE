# Adobe Commerce Developer Agent Connect-Integrationen

Generierter Code benötigt einen Ausführungsort und eine Verbindung zu Ihrem Store. In dieser Phase wird alles integriert - das Hosten des Codes in App Builder, das Verbinden mit Ihrer Adobe Commerce-Instanz und das Verknüpfen eines GitHub-Repositorys - bevor die Funktion aktiviert wird.

## Für wen ist dieses Video bestimmt?

* Commerce-Entwickler
* Lösungsarchitekten
* Backend-Techniker

## Videoinhalt

* Erstellen eines App Builder-Projekts und -Arbeitsbereichs zum Hosten des vom Entwickleragenten erstellten Codes
* Agent-Strukturvorlage beobachten, um das Projekt und die ausstehenden Setup-Elemente der Oberfläche zu finden
* Hinzufügen der erforderlichen Adobe Commerce as a Cloud Service-API-Anmeldeinformationen in der Developer Console
* Verbinden des Codes mit einer bestimmten Adobe Commerce Cloud Service-Instanz
* Zum Speichern und Veröffentlichen des Codes verknüpfen Sie ein GitHub-Repository
