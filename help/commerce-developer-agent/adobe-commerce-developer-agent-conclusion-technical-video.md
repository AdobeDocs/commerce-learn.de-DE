# Adobe Commerce Developer Agent - Schlussfolgerung

Diese kurze Zusammenfassung fasst die Adobe Commerce Developer Agent Journey zusammen - von einer einfachen englischen Anforderung oder einer veralteten Erweiterung zu einer funktionierenden, getesteten Store-Funktion ohne manuelle Codierung.

## Für wen ist dieses Video bestimmt?

* Commerce-Entwickler
* Lösungsarchitekten
* Entwicklungsleiter

## Videoinhalt

* Eine Zusammenfassung des End-to-End-Flusses, von der schriftlichen Anforderung bis hin zu einer bereitgestellten, getesteten Speicherfunktion
* Wie derselbe Workflow angewendet wird, egal ob Sie mit einer einfachen Beschreibung beginnen oder eine vorhandene Erweiterung migrieren
