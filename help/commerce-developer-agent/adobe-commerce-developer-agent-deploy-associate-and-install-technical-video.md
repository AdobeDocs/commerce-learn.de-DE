# Adobe Commerce Developer Agent bereitstellen, verknüpfen, installieren

Mit allem, was verbunden ist, ist die App produktionsbereit. In dieser Phase wird der Code bereitgestellt, dann verknüpft und in Adobe Commerce Admin installiert, damit die neue Funktion im Store aktiviert wird.

## Für wen ist dieses Video bestimmt?

* Commerce-Entwickler
* Lösungsarchitekten
* Commerce-Administratoren

## Videoinhalt

* Einholen der Bereitstellung durch den Entwickleragenten aus dem Chat und Bestätigung der genauen Organisation, des Projekts und des Arbeitsbereichs
* Führen Sie eine Validierung vor der Bereitstellung durch, und dann erfolgt die Streaming-Erstellung und -Veröffentlichung, wenn der Code bereitgestellt wird.
* Verknüpfen der bereitgestellten App mit einem bestimmten Store über den Bildschirm „App-Verwaltung“ der Commerce-Admin-App
* Überprüfen der App-Karte — Name, Version und die damit hinzugefügten Funktionen (Webhook)
* Installieren der App zum Aktivieren der Funktion und Bestätigen der erfolgreichen Installation
